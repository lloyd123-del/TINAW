# TINAW - IoT Crayfish Monitoring System

## Project Structure
- **frontend/** - React Native mobile application
- **backend/** - Node.js/Express API server

## Prerequisites
- Node.js
- npm or yarn
- React Native CLI or Expo CLI
- MongoDB/PostgreSQL (depending on your backend)
